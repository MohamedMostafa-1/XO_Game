# XO_Game

A simple **Tic-Tac-Toe (XO) Game** built using **C# and Windows Forms**.

## 🎮 Features

- Two-player XO game
- X and O turns
- Winner detection
- Draw detection
- Restart/New Game
- Simple and clean UI
- Built with Windows Forms

## 🛠️ Technologies

- C#
- .NET
- Windows Forms
- Visual Studio

## 🎯 How to Play

1. Player **X** starts the game.
2. Players take turns choosing an empty cell.
3. The first player to get **3 symbols in a row** wins.
4. A player can win horizontally, vertically, or diagonally.
5. If all cells are filled without a winner, the game is a **Draw**.
